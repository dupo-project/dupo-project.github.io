# Changelog

All notable changes to DUPO are recorded here.

## 0.1.0 - 2026-08-28

- Published the DUPO/DeepAction training core and reward implementation.
- Added a configurable, dry-run-capable training entry point.
- Added bilingual quick starts and installation, data, training, evaluation, algorithm, and reproducibility documentation.
- Added deterministic data preparation, a synthetic schema fixture, a CPU-only reward smoke test, and repository-hygiene checks.
- Added mixed-license notices for original DUPO materials and the vendored Apache-2.0 verl subtree.
- Documented the implementation and requirements for exact paper reproduction.
